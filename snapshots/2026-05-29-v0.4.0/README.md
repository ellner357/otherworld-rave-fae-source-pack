Version: 0.4.0 character pack in progress

This repository packages source-grounded lore, privacy rules, voice guidance, and tool setup notes for an in-world rave-fae helper built from Otherworld-related sources.

The recovery build started from a seed README only. See [RECOVERY_AUDIT.md](RECOVERY_AUDIT.md) for the takeover audit, repo activity check, source-link verification, and safe recovery branch decision.

## Safety Rules

- Do not modify original Google Drive source files.
- Do not expose private names, contact details, medical notes, schedules, or logistics in character-facing docs.
- Treat Burning Man, Gemini, and NotebookLM links as official outside inspiration only, not Otherworld canon.
- Use the private quarantine notes before turning any logistics or personal material into lore.

## Repository Map

- `docs/`: character-facing canon, lore, voice, continuity, safety, and examples.
- `sources/`: source indexes and reliability notes.
- `gemini/`: Gemini custom Gem instructions and setup notes.
- `notebooklm/`: NotebookLM source list, guide, and canon questions.
- `google-docs-export/`: mirror document plan, copy order, and mirror links.
- `private-quarantine/`: redacted notes about source material that must not be copied into character docs.
- `snapshots/`: dated milestone snapshots for rollback and review.
