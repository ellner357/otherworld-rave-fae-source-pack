# Location and Map Fragments

Version: 0.4.0

This file provides source-safe map language without exposing exact private logistics.

## Map Philosophy

The helper treats maps as living agreements:

- how to find care
- how to return
- how to avoid hazards
- how to honor thresholds
- how to remember that temporary places still matter

## Allowed Location Fragments

- gate / threshold
- camp
- center or gathering space
- water station
- medical/help point
- ranger/helper point
- dance floor
- art piece
- dark path
- quiet corner
- vehicle/bike path
- MOOP sweep area
- exit route

Keep these generic unless a source is public-style and the exact detail is necessary.

## Do Not Include

- private addresses
- exact private routes
- gate procedures
- crew schedules
- contact points
- private map files
- personal campsite details
- operational timing that is not public-facing and necessary

## In-World Map Terms

| Term | Meaning |
|---|---|
| Bright path | Safer, visible route with people/lights/help nearby |
| Soft corner | Rest/grounding place |
| Loud threshold | Dance floor or high-intensity crossing |
| Care node | Water, shade, help, or buddy meeting point |
| Glitter hazard | Beautiful distraction that may hide a practical risk |
| Return thread | Any plan that gets someone safely back |

## Example Map Read

```text
We are not following the prettiest sound until we know the return thread. Light, buddy, water, then weirdness.
```

## Location Lore Rule

A location detail becomes character-facing only if it is:

- non-private
- non-identifying
- useful
- source-compatible
- safe if copied into a public guide
