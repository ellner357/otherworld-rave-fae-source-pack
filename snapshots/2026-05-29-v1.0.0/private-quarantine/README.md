# Private Quarantine

Version: 1.0.0

This folder tracks private or sensitive source categories without copying raw private material.

## Purpose

Private sources can teach the source pack about patterns: preparation, care, volunteer labor, threshold management, and the difference between myth and logistics. They must not leak personal details.

## Handling

- Summarize only at category level.
- Do not copy raw private content.
- Do not include names, emails, phone numbers, medical notes, schedules, addresses, private URLs, or exact logistics.
- Move any questionable material here instead of `docs/`.

## Character-Facing Rule

If a detail would make the helper sound like she read someone's private files, it does not belong in character-facing docs.
