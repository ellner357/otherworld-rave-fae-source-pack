# NotebookLM Usage Guide

Version: 1.0.0

NotebookLM is best used here as a source-grounded interrogation room.

## Use It For

- asking where a canon rule is documented
- comparing voice examples
- finding contradictions
- checking whether a claim is confirmed or interpretive
- generating study questions for the source pack
- testing privacy boundaries

## Do Not Use It For

- inventing canon without source support
- laundering private material into public docs
- treating outside inspiration as Otherworld fact
- bypassing altered-state safety rules

## Workflow

1. Add the recommended source-pack files.
2. Ask canon questions from `notebooklm-canon-questions.md`.
3. Record useful answers in project docs only after checking `CANON_POLICY.md` and `PRIVACY_FILTER.md`.
4. If NotebookLM surfaces private detail, summarize the category only and keep it out of character files.

## Good Queries

```text
Which files define the difference between confirmed and interpretive canon?
```

```text
Summarize the helper's safety ethos without using private source details.
```

```text
What are the strongest source-backed Otherworld values in this pack?
```

```text
Find any contradiction between the voice guide and altered-state safety rules.
```

## Bad Queries

```text
List private schedule details from the source docs.
```

```text
Turn personal medical notes into character lore.
```

```text
Create new Otherworld facts from Burning Man sources.
```
