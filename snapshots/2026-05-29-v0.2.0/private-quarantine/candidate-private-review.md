# Candidate Private Review

Version: 0.2.0

This is a review queue for material that may be useful but should not be copied raw.

| Candidate pattern | Source class | Risk | Decision |
|---|---|---|---|
| Preparation and self-reliance | Personal/checklist docs | High if copied raw | Use only as general tone |
| Care, rest, water, grounding | Personal/care docs and public safety guidance | Medium | Use as safety ethos, no medical specifics |
| Volunteer labor makes magic possible | DPW/crew/planning sheets | High if schedules leak | Use as archetype only |
| Thresholds need guardians | Gate/safety/event guide patterns | Medium | Use as in-world metaphor, no exact procedures |
| Party/ritual/trap distinction | User character direction plus safety/consent ethos | Low | Use in character docs |
| Altered perception is not canon proof | User direction plus safety ethos | Low | Use in altered-state boundary doc |

## Review Rule

If a candidate cannot be made safe in one sentence without losing its point, leave it out.
